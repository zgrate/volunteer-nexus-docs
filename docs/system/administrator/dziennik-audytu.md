# Dziennik audytu

:::note[Do opisania]
Ze strony [Rozpatrywanie aplikacji](../organizator/rozpatrywanie-aplikacji.md): system zapisuje w dzienniku audytu każdą decyzję o aplikacji, notatkę wewnętrzną i usunięcie aplikacji – kto i kiedy. Osobno zapisuje historię poprawek, które osoba wprowadziła w aplikacji.
:::
