# Dziennik audytu

:::note[Do opisania]
Ze strony [Rozpatrywanie aplikacji](../organizator/rozpatrywanie-aplikacji.md): system zapisuje w dzienniku audytu każdą decyzję o aplikacji, notatkę wewnętrzną i usunięcie aplikacji – kto i kiedy. Osobno zapisuje historię poprawek, które osoba wprowadziła w aplikacji.

Ze strony [Działy i zespoły](../organizator/dzialy-i-zespoly.md):

- system zapisuje każde dodanie, zmianę i usunięcie członkostwa: kto i kiedy,
- przy usunięciu z działu zapisuje usunięte zadeklarowane godziny osoby dla tego działu,
- przy usunięciu z wydarzenia zapisuje usunięte przepracowane godziny i benefity osoby.

:::
