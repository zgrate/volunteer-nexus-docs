# Mailer

:::note[Do opisania]
Zasady przeniesione ze strony [Sposoby kontaktu](../wolontariusz/sposoby-kontaktu.md):

- organizator może wysłać wiadomość do wybranych osób, do członków działu albo do wszystkich uczestników wydarzenia,
- wysyłający wybiera sposób dostarczenia; opcja „preferowany kanał” wysyła wiadomość każdej osobie kanałem, który ta osoba wybrała,
- wiadomość trafia też do skrzynki powiadomień osoby,
- osoba nie może wyłączyć wiadomości wysłanych przez Mailer,
- system nie ma czatu: organizator pisze w systemie do pojedynczej osoby tylko przez Mailer, a osoba nie odpowiada organizatorowi w systemie.

:::
