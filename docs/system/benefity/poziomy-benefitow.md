# Poziomy benefitów

:::note[Do opisania]
Zasady opisane dotąd na stronach [Aplikacja wolontariacka](../wolontariusz/aplikacja.md) i [Rozpatrywanie aplikacji](../organizator/rozpatrywanie-aplikacji.md):

- poziomy są zdefiniowane z góry, a ich lista jest wspólna dla wydarzenia,
- osoba wybiera poziom w formularzu aplikacji; wybrany poziom jest przypisany do konkretnej aplikacji,
- akceptacja aplikacji blokuje poziom – od tej chwili zmienia go tylko organizator.

:::
