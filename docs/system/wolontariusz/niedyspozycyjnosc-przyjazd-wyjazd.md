# Niedyspozycyjność, przyjazd i wyjazd

:::note[Do opisania]
Ze strony [Aplikacja wolontariacka](aplikacja.md): formularz aplikacji nie pyta o przyjazd i wyjazd. Osoba podaje je po przyjęciu.

Ze strony [Definicje i podstawowe typy zmian](../zmiany/definicje.md):

- zgłoszenie niedyspozycyjności działa od razu; organizator może je odrzucić, podając powód,
- niedyspozycyjność pełna blokuje przydział do zmiany w tym czasie, warunkowa tylko ostrzega planującego,
- w siatce godzin kategoria oznaczona jako blokada tworzy niedyspozycyjność wolontariusza.

:::
