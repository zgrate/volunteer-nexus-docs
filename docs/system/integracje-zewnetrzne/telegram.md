# Telegram

:::note[Do opisania]
Zasady opisane dotąd na stronie [Rejestracja i logowanie](../wolontariusz/rejestracja-i-logowanie.md):

- kontakt na Telegramie jest wymaganą daną profilu: nazwa użytkownika albo połączenie konta z Telegramem,
- osoba, która wybrała Telegram jako kanał powiadomień, dostaje tam także kod logowania.

Ze strony [Profil wolontariusza](../wolontariusz/profil.md):

- jedno konto na Telegramie można połączyć tylko z jednym kontem w systemie,
- po połączeniu nazwę użytkownika ustawia Telegram, a osoba nie wpisuje jej ręcznie,
- gdy osoba nie ma zdjęcia profilowego, system używa jej zdjęcia z Telegrama,
- Telegram można wybrać jako kanał powiadomień dopiero po połączeniu konta,
- rozłączenie przywraca e-mail jako kanał powiadomień, także dla kodu logowania.

Ze strony [Sposoby kontaktu](../wolontariusz/sposoby-kontaktu.md):

- gdy osoba zablokuje na Telegramie bota systemu, system nie może do niej pisać; profil pokazuje wtedy ostrzeżenie, a Telegramu nie da się wybrać jako kanału powiadomień, dopóki osoba nie odblokuje bota,
- wiadomość, której nie da się dostarczyć na Telegramie, system wysyła e-mailem.

:::
