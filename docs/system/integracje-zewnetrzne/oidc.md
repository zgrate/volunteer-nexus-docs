# OIDC

:::note[Do opisania]
Zasady opisane dotąd na stronie [Rejestracja i logowanie](../wolontariusz/rejestracja-i-logowanie.md):

- dostawca logowania nie zakłada kont; loguje tylko do konta, które już istnieje,
- konto dopasowuje się wyłącznie po adresie e-mail,
- gdy konta nie ma, system odmawia i informuje, że konto nie istnieje,
- wylogowanie kończy także sesję u dostawcy,
- listę dostawców ustawia administrator.

:::
